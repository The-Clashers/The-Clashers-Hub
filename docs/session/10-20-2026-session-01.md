## Decisions

- React 19 + react-native-web 0.20: the RNW line that targets React 19.
  Keeping every package on one React version is what makes the component
  types agree, so this pairing over mixing 18 and 19.
- Types for the `react-native` module come from the react-native package
  itself, installed as a dev dependency for typing only. The bundler
  alias keeps react-native out of the bundle, react-native-web is what
  actually runs.
- React Router v7 in library mode, same API the docs describe
  (BrowserRouter, Routes, useParams).
- Query defaults: staleTime 60s, retry 1, no refetch on window focus.
  The server TTL cache owns freshness, the client stays conservative.
- The build script runs the typecheck first, so the zero-errors gate is
  baked into every build and later into CI for free.
