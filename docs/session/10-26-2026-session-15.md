## Decisions

- The dropdown exists because the game API draws a hard line the UI must not blur: there is no player search by name, so a player is reachable by tag only, while a clan is reachable both by name (the search bar) and by tag (this box). The box's dropdown is the method selector for that fact, the same control family the filter row already uses.
- Default target is Player, so golden path B is exactly what it was: paste a tag, press Go, land on the player. Selecting Clan repoints the same box at the clan screen; the tag alphabet is shared, so switching targets does not clear or revalidate the draft.
- The target dropdown reuses the session 14 `Dropdown` with a new `hideLabel` prop instead of a second control. The hidden label keeps the ARIA wiring identical (aria-labelledby still names the listbox); only the pixels go away, because the row already shows "Look up by tag" on the left.
- The placeholder is now "Paste a tag, # optional", shared by both targets. The old sentence truncated mid-word at the 360 px compatibility floor (the input is 242 px wide there); the full instruction moved into the accessibility hint, which is where a sentence belongs anyway.
- These changes ride PR #14 rather than a new PR: that PR is still open, and this is the same polish pass it exists for (its branch is where the work landed).
