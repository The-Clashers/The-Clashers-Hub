## Decisions

- The owner's direction was that the existing clan search box learns the tag path, not that the tag box learns clans. Session 15 had it backwards: it bolted a Player/Clan dropdown onto the tag box and left the search bar name-only. This session swaps the capability to the box it belongs on.
- A leading `#` is the one honest way to say "tag, not name" in the search bar. Bare tags and names share the [0-9A-Z] alphabet (a clan can be named USA), so auto-detecting a bare tag would hijack real name searches. The player box can still afford "# optional" because it accepts nothing else.
- The tag path skips the listing and goes straight to the clan detail screen, the same destination the result cards link to, through the same `clanRouteFor`. Filters are ignored on the tag path (they narrow name searches), and the idle copy says so.
- SR-13's "exactly one place" now names the module, not the component: the rule and its reject sentences live in `lib/tag.ts`, and two inputs call it. The wording moved with the rule because two boxes saying different words for the same broken tag would be its own defect. Each box still owns its empty prompt, since only the box knows what else it accepts.
- The `#tag` branch keeps the same clear-on-fix behavior as the tag box: the hint drops the moment the input normalizes to a valid tag (or stops starting with `#`), without waiting for the next submit.
- The `minWidth: 0` fix rides this PR because the overflow was found verifying it and the PR is the open polish pass for this screen. The responsive side-padding tokens (`sidePaddingMobile`, `sidePaddingSmall`) exist but are still unwired; wiring them is a separate decision for the design pass, not a drive-by here.
- Verified in the browser at desktop and 360 px: name search "Destruction" returns the live card list; `#2CJPGCLUC` in the search bar navigates to `/clan/%232CJPGCLUC`; `#AB`, `#AB!`, and a blank submit show their hints; the hint clears on fix; `jgycpcuj` in the player box normalizes to `/player/%23JGYCPCUJ`; the player box's empty-submit hint (the session 14 fix) still shows; no console errors; no horizontal scroll at 360 px. Typecheck, lint, and all 63 tests pass.
