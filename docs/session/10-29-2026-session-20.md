## Decisions

- The KanbanFlow card carries AC-02 (the needs-attention toggle and ratio
  chip), but the tracker maps that criterion to T-M1-5 with FR-05 and SR-12.
  Per 02 section 11 the tracker wins, so this card ships the three subtasks
  it actually names (sortable columns, tap-through, card switch) and the
  donation flags land with the engine card.
- The sort rule lives in `lib/`, not in the components (STD-09): the
  comparator, the press cycle, and the tiebreak chain are pure and tested
  without rendering anything. The three-state cycle keeps clan order as a
  first-class state because that order (trophy rank) is the one every
  player knows from the in-game roster.
- `RosterTable` and `RosterCard` went into `src/components/` because the 07
  section 4 inventory names them. `RosterCard` is one member card (the
  granularity of `ClanCard`); the card list's FlatList lives in the screen
  file with the sort state, because a roster-with-sort is clan-detail
  specific (STD-16): the M3 scouting view renders rosters but never sorts
  them.
- Table semantics follow the keyboard path the design language documents:
  the container carries the grid role, the header carries row and
  columnheader roles with the sort control as a button inside each sortable
  columnheader, and body rows are links whose label reads the full member.
  Cell roles inside a link would be orphaned ARIA, so the label carries the
  row instead.
- The grid wrapper View around the table's FlatList must carry `flex: 1`.
  RN Views do not shrink by default, so without it the table overflows the
  bounded tab region, the page scrolls instead of the list, and both
  virtualization and the sticky header are silently lost. The tab region
  itself flexes with a 320 px floor, the same trade the search screen's
  results area makes: on tall viewports the roster owns its own scrolling,
  on short ones the page grows.
- The Enter-key fix touches two surfaces beyond this card (PillButton and
  ClanCard) because the gap is one react-native-web behavior shared by
  every link-role Pressable, and the DoD's keyboard-usable gate applies to
  the golden path this screen completes. The rule lives in one module so
  the RN Web coupling is written down once; Space stays a scroll key
  because native anchors activate on Enter only.
- League icons come from the game API's own iconUrls at 24 px (07 section
  7), including the API's Unranked league object, so no bundled placeholder
  is needed for unranked members.
