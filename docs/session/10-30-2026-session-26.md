## Decisions

- The # column is the position in the rendered order, not the API's
  clanRank: in clan order the two agree, but under any other sort clanRank
  would jump around the table while the position runs 1, 2, 3 and says
  "this is the order you are looking at", the same semantics the
  needs-attention table's number column already owns.
- The war log's visibility is a stat cell, not a badge on the identity row:
  it is one fact among the war facts (frequency beside it), the grid keeps
  every datum the same shape, and the Log tab's M3 view will say the rest.
- The stat grid is one flat uniform wrap, no group headings: the labels
  (Members, Points, War wins, Win streak, War, War log, Trophies req,
  TH req) carry the grouping, and a heading row per group would spend
  vertical space saying what the labels already say.
- The sentinel over an onScroll listener: the browser already computes
  intersection, the callback fires only when the answer changes, and the
  400 px rootMargin buys the look-ahead a scroll handler would have to
  measure by hand. The observer re-fires on recreation, which is what
  keeps a still-visible bottom loading the next page.
- 30 per page stands (the tier's SEARCH_PAGE_LIMIT): the owner's "still
  limit it by 30" matches the acceptance budget (AC-01's cold fetch), and
  the sentinel adds pages without changing the first-load cost.
- scrollbar-gutter over overflow-y: scroll: the gutter reserves the space
  without painting a dead scrollbar track on every page, which is the
  standard professional behavior; overlay-scrollbar platforms ignore it
  harmlessly.
- The token review link is a muted text link, not a PillButton: the
  contributors page is a visitor-facing credits page and the review
  surface is maintainer QA, so the link reads as fine print instead of an
  action competing with the list (the owner's "style it differently").
- The roster's name column keeps a 160 px flex basis with the metric
  columns growing a 0.4 share each rather than capping the name with a
  maxWidth: a capped flex column leaves dead space at the row's end on
  wide viewports, while shared growth fills the row edge to edge.
