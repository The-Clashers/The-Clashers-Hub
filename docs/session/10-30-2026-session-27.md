## Decisions

- /hello retired, /tokens kept: the owner's rule was "remove the screens
  that will not be used anymore since it will just be duplicates with
  different name". /hello is a strict duplicate of /clan/:tag (same fetch,
  same states, hardcoded tag); /tokens renders a surface nothing else
  renders and the contributors page links it; /compare is a future P1
  landing, not a duplicate.
- The clan helper line teaches the leading-# rule, not the tag-format rule
  the player footnote teaches: each input's helper says what that input
  needs (where a player tag lives vs how a # input behaves), which keeps
  the pair parallel without repeating the same sentence twice.
- The attention table reuses the roster's constants rather than a shared
  module: the two tables are separate presentations with different column
  sets; the shared thing is the rule (fixed leaders, modest name basis,
  small grow share), and both files now state it in the same words. A
  shared constants module would couple two components that 07 section 4
  deliberately keeps separate.
- The AttentionCard keeps its "#N" prefix while the table drops it: on the
  card the worst-first position is data (the engine's verdict order), not
  presentation chrome, and the roster's card renders no position at all;
  the table's plain number matches the roster table's family instead.
- No merge without the owner's approval: the PR stays open for review
  (this session's standing instruction).
