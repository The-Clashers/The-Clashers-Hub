## Decisions

- The cap tables live in src/lib/, not src/engines/. The bundle is data
  with lookup functions, no analysis; engines and lib both import it fine
  under the 01 section 5 boundaries (engines may not import React; the
  tables import nothing). The concept's phrase "bundled reference data"
  never names a folder, and 09 section 2 already routes icon-map.ts (the
  other half of the bundle) to lib.
- Gate chains over raw townHallRequired: the dataset marks eleven final
  spell and siege researches TH17 while requiring laboratory 16, and lab
  16 first exists at TH18. Trusting the raw field would have placed a
  TH18-only level one hall early. The derivation resolves every level
  through the building that performs it, which is what the game itself
  enforces.
- Inferno Dragon maps to Baby Dragon, not Dragon. Three independent
  witnesses agree: the dataset records the variant link on Baby Dragon's
  own file, the live payload reports Inferno Dragon maxLevel 12 (Baby
  Dragon's global maximum; Dragon's is 13), and the boost arrived with
  Baby Dragon's ladder. The old mapping was a plausible guess from the
  scoring doc's example table that no payload had ever verified.
- Super troops stay absent from the cap tables. They are temporary
  variants on their base troop's ladder; the engine drops them through
  SUPER_TROOP_MAP before it ever reads a cap, so rows for them would be
  dead data that could drift silently. The completeness test asserts the
  split from the other side: every super name resolves in the map, none
  in the tables.
- Halls beyond the table clamp to the last column rather than returning
  null. A TH19 payload reading TH18 caps is the honest state (nothing new
  is known about TH19), and a null would push every unit into the
  skipped footnote, which would read as broken analysis rather than
  slightly-stale analysis.
- The generator script stays outside the repo (scripts/ in the sandbox,
  not the project's scripts/): it depends on the vendored dataset clone
  and the live payload snapshot, neither of which belongs in the repo.
  The emitted module is the artifact; the module header records the
  derivation so the numbers stay reviewable without the generator.
