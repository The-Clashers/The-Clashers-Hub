## Decisions

- The undo restores the old layout, not the old page: the graph work from
  session 39 (the gauge, the category bars, the upgrade-next list) stays —
  the owner's feedback was about the card's design and the icons' layouts,
  so the analysis cards now stack in the analysis column the old layout
  gives them.
- The two buttons keep the 44 px touch floor while following the
  prototype's button design (pill, gold, leading glyph): the floor is a
  documented accessibility rule (07 section 6) and the prototype is a
  proposal; the visual language is the pill + glyph, not the 30 px height.
- The cached pill carries the last-refresh text rather than a bare line:
  the prototype's own treatment, and it gives the "small text of the time
  of last refresh" a shape that survives next to a button.
- Measured grids over media queries: the hero cards and the progression
  tiles read their width from onLayout because the shared breakpoints
  helper only knows the window, and both grids live inside flex columns
  whose inner width the window cannot predict.
- The progression tile's MAX badge keeps the prototype's corner break
  (top -7, right -5): it overhangs the tile border by design, the way the
  prototype's own `.t-max` does.
- The star glyphs moved from text characters to the Glyph set's filled
  star: the prototype's rating is a filled shape, and the kit now owns an
  SVG glyph set anyway (the ProgressRail comment's "no chart dependency
  yet" premise died with session 39's Gauge).
