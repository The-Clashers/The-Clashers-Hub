## Decisions

- Added panelHighlight token for crisp glass top edge lighting across panels and controls.
- Added accentInk token (#855600 light, #F2C14E dark) to fix gold text contrast on soft gold surfaces, reaching 5.6:1 contrast.
- Adopted cool slate canvas (#F3F5F9) for light mode and deep slate-black (#0A0D13) for dark mode with refined amber-gold accent.
- Bundled Inter Variable font locally using @fontsource-variable/inter to avoid external runtime CDN requests while maintaining clean typography.
- Switched interactive control heights to density-aware layout: 36px on desktop and tablet, 44px on mobile, keeping 44px as touchTargetMin accessibility floor.
- Adjusted hero and achievement card container width threshold to 260px and locked identity column width to 320px so 2-column layout persists reliably across zoom levels and 1024px desktop widths.
- Removed directional top border highlight from tile and unit sub-items to eliminate missing/severed borders on maxed golden badges.
- Updated player identity card layout to pair league crest directly with player name and clan tag, position stacked refresh control at top right, arrange stats in a 2x2 grid, and ground the card with a full-width compare button.
- Bound lookup search hint to route changes, onBlur, and a 3.5s auto-dismiss timer so search hints never permanently float outside the navbar.
