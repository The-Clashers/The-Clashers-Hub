## Decisions

- A private war log is a success shape, not an error: the tier answers `200 { private: true }` and the client returns it as a discriminated union member, so the screen renders the designed notice (CON-05, AC-05) and the error branches stay for the contract's four failure kinds only.
- Clan War League seasons ride the same warlog page with season-total stars, destruction beyond any percentage, no verdict, and a degenerate opponent. The parse tags them by the league's one-attack-per-member signature, the row shows the season's own totals (stars, attacks, end date) without opponent figures or a per-war allowance, and the summary sets them apart from every rate with the caption naming the count. Live browser verification caught this: the first render averaged 241.9% "destruction" before the rule existed.
- The format check runs before the verdict: the live API reports an occasional tie on a league season, and a season carrying a verdict must still read as a league or its totals poison the rates (the second render's 114.5% was exactly that entry). A regular war always allows two attacks per member, so the format check cannot swallow one.
- Average destruction is attack-weighted: each war's percentage is already an average per attack used, so the clan-wide figure weights every war by its own attack count. Verified against the smoke clan's live page (82.2% in the browser matches the hand-computed 82.17%).
- Win rate is wins over decided wars (wins + losses + ties); an ongoing regular war stays out of the quotient but its attacks still count toward the attack rates, since stars and destruction are facts of the attacks, not of the verdict.
- Log rows are not links: a logged war is a fact to read, not an entity to open. Opponent-clan tap-through stays a later call if the log earns it.
- The stat grid's public/private cell (F-04) already warns before the tab opens; the notice's next action is the current war, which answers regardless of log privacy.
- Session 51's key blocker is resolved: the fresh COC_API_TOKEN answers through the proxy again, so this session ran the whole verification loop on live data (local tier + vite preview, both states and both presentations).
