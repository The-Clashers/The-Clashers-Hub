## Decisions

- **Impact ordering is stars, then best-attack quality, then average destruction, with the war map breaking every tie.** The scoring engines doc says "ordered by impact among participants" without fixing a formula, so the engine reads impact as the game's own scoring order (stars first, destruction-style quality as the tiebreak) and falls back to the map's order on exact ties, so the table never invents a ranking the payload did not state.
- **Zero-attack members keep their map order after the participants and are never averaged in as zeros.** The idle-order comparison sorts explicitly by map slot (unknown positions keep payload order), so the rule holds even if the payload's roster ever arrived out of map order.
- **The baseline is per side, not per war.** Each roster's caption and colors read against that roster's participant average; an opponent having a stronger sheet does not recolor the clan's own table.
- **The baseline coloring is the table's job, not the cards'.** The card presentation carries the quality value as a plain chip; the compact view stays quiet and the table is where the success/danger verdicts speak, matching how the compare rows treat direction colors.
- **Positions are resolved before reordering.** `warMemberPositions()` snapshots each member's war-map number from the payload's original roster order, so the reordered rows still show the positions players know from the game's war screen.
