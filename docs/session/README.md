# The Clashers Hub: Session Notes

One file per lab session, named `session-NN.md` (session-08.md,
session-09.md, ...). Start each one from [_template.md](_template.md):
copy it, fill in what applies, delete what does not. Write it during
or right after the session; these notes are the raw material for the
course report in M4.

The card IDs referenced in each note match the KanbanFlow board; the
task breakdown with estimates is [§11](../../requirements.md).

## Conventions

- One note per session, written the same day; late notes get shorter
  and wronger.
- Card IDs, feature IDs and requirement IDs stay exactly as they are
  elsewhere in the docs; never renumber anything to match a session.
- A session note records what happened and why; the
  [concept docs](../concept/README.md) carry the decisions forward.
  Change those too, in the same PR, or the two drift apart.
